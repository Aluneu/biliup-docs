::: info
* 直播间链接格式：`https://www.douyu.com/123456`（123456 为房间号）。
* 默认下载器 `mesio` 即可录制；v1.3.0 起斗鱼插件内置网页播放签名，**不需要再安装 JavaScript 解释器**。
* 斗鱼支持弹幕录制，开启后弹幕以 B站兼容 XML 格式保存。
:::

::: warning v1.3.0 起：原画等高码率需要登录
2026-09 起，斗鱼把原画 / 蓝光等高码率档位收紧到登录会话：未登录通常只能拿到「超清」，部分房间还会录制几分钟后断流。要稳定录原画，请配置**登录 Cookie**（`douyu_cookie`），并建议同时配置自动续期。
:::

## 登录 Cookie（douyu_cookie）

### 获取 Cookie

1. 浏览器登录斗鱼，按 `F12` 打开开发者工具 → **Network**；
2. 刷新直播间页面，选一个发往 `www.douyu.com` 的请求；
3. 复制请求头里的整段 `Cookie`；
4. 打开 WebUI「空间配置 → 平台设置 → 斗鱼 → 登录 Cookie」，粘贴后点「**测试 Cookie**」。

也支持 EditThisCookie 等扩展导出的 JSON 数组，**直接粘贴内容**（不是文件路径）。要求：

- `acf_uid`、`acf_auth` 必须非空；
- 不要手动解码 `%xx`；
- 不要把不同账号的导出拼在一起。

### 自动续期（LTP0 + dy_did）

Cookie 会过期，biliup 可以用 passport 的长期凭据自动续期：

| 配置项 | 说明 |
|---|---|
| `douyu_ltp0` | 长期续期凭据 `LTP0` |
| `douyu_refresh_device_id` | 配套的 Web 设备号 `dy_did` |
| `douyu_auto_refresh` | 是否自动续期，有 `LTP0` 时默认开启 |

要点：

- `LTP0` 与 `dy_did` 必须来自**同一账号、同一次浏览器登录**；
- 完整 JSON 导出里已含 passport 条目时，这两项可以留空；
- 续期成功后 3 天一次，每分钟检查；临时错误从 5 分钟指数退避到最多 6 小时，凭据失效退避 24 小时；
- 续期状态保存在本机 SQLite 的 `douyu_cookie_keeper` 表（不加密，Unix 下权限 `0600`）。

| 界面操作 | 作用 |
|---|---|
| 测试 Cookie | 只校验输入框里的内容（实际调用关注列表接口），不保存、不续期 |
| 手动续期 | 用已保存的配置续期；同一来源最短 60 秒一次，需要 `config.edit` 权限 |

### 房间级用法

「直播管理 → 房间 → 配置覆写 → 斗鱼」三选一：

- **继承空间配置**（默认）；
- **此房间独立 Cookie**——要自动续期，必须自带完整凭据；
- **匿名取流**。

## 画质与编码（douyu_rate / douyu_codec）

`douyu_rate` 是**请求的最高档位**，实际档位由平台返回：

| 值 | 档位 |
|---|---|
| `0` | 原画 |
| `8` | 蓝光 8M |
| `4` | 蓝光 4M |
| `3` | 超清 |
| `2` | 高清 |

`douyu_codec` 默认 `AVC`。选 `HEVC` 时：

- 平台没有 HEVC 会回退 AVC 并在日志里提示；
- HEVC / AV1 用 `mesio` 或 `stream-gears` 都能录；用 FFmpeg 需要支持实际 FLV 的新版本。

::: tip 核对画质看 ffprobe，不看 URL 后缀
```bash
ffprobe -v error -select_streams v:0 -show_entries stream=codec_name,width,height,avg_frame_rate <录制文件>
```
:::

网页接口失败时 biliup 会回退 App 接口，画质可能受限；这是平台侧行为，不是配置问题。

## 弹幕录制（douyu_danmaku）

* 斗鱼弹幕通过 TCP（STT 协议）获取，开启「弹幕录制」后即可录制对应直播间的弹幕。
* 弹幕输出为 B站兼容的 XML 格式。v1.3.0 起 XML → ASS 转换已内置（原生 Rust 实现，排版派生自 [DanmakuFactory](https://github.com/hihkm/DanmakuFactory)），**不需要再单独安装 DanmakuFactory**；如需压制画面，见[录后合成](/guide/tutorials/post-recording-render.html)。

---

## CDN 切换与 `Non-monotonous DTS`

斗鱼 CDN 切换节点或主播推流重连时，FLV 流的时间戳常会归 0，日志形如：

```
Non-monotonous DTS in output stream; previous: 4877, current: 0
```

v1.3.0 起 biliup 会按音频、视频轨道**分别**把后续时间戳平移接上，跳过切换瞬间的空 tag / 残缺 tag 与重发的 FLV 文件头，录制继续进行；连接在 tag 中间断开时按正常断流结束，已录内容全部保留。**这条日志只是提示，不需要处理。**

## 跳过互动游戏（douyu_disable_interactive_game）

* 开启后跳过直播间内的「互动游戏」内容，避免录制到无关画面。默认关闭。
