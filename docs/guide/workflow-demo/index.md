# biliup 工作原理与快速引导

biliup 把直播和本地视频推送到 B 站等平台，同时提供一个 WebUI 管理界面。下面先说明一次完整的处理流程，再带你跑通第一个录制任务。

> 链路随来源切换：直播走「直播链路」，本地文件走「本地链路」；输出目标通常是 B站投稿，也可配置为只录制不上传。

## 第一次成功：从录制到投稿

下面以 Docker 部署为例，串起「安装 → 启动 → 登录 → 添加平台账号 → 创建投稿模板 → 绑定主播 → 完成一次录制和投稿」的完整路径。其他安装方式见[安装部署](/guide/getting-started/安装部署/docker.html)。

::: danger 照做前必读（避免「只录制不投稿」或「录像被误删」）
1. **默认上传器是 `Noop`（只录制、不上传）**。要让录完自动投稿，必须创建投稿模板并选择非 `Noop` 的上传器（如 `biliup-rs`），再把模板绑定到主播。
2. **新建主播默认带 `rm` 后处理**：即使没配置上传、或用了 `Noop`，下播后本地录像也可能被删除。确认要保留本地文件前，请先移除该默认 `rm`，或改用安全的保留策略。
:::

### 步骤 1：启动服务并开启认证

运行 `biliup server --auth`。`--auth` 是开关，不接收密码；首次访问 WebUI 时**管理员用户名固定为 `biliup`**，请设置密码（这是 WebUI 管理员账号，不是 B站账号）。
参考：[Docker 安装指引](/guide/getting-started/安装部署/docker.html) · [Windows 安装](/guide/getting-started/安装部署/windows.html)

### 步骤 2：登录 B站账号（投稿用）

在 WebUI 中扫码或填入 Cookie 完成 B站账号登录。这是「投稿账号」，与步骤 1 的管理员账号是两套不同身份。
参考：[B站账号登录](/guide/getting-started/配置/login.html)

### 步骤 3：创建投稿模板

进入「投稿管理 → 模板管理 → 新建模板」，填写最小必填项（投稿账号、分区、标题 / 简介 / 标签等）；**上传器选择 `biliup-rs`**（不要用 `Noop`）。
参考：[WebUI 使用指南 - 投稿模板](/guide/webui/usage.html)

### 步骤 4：添加主播并绑定模板

在「录播管理」添加直播间链接；编辑该主播，「上传插件」选 `biliup-rs`、「投稿模板」选步骤 3 创建的模板。
同时检查「分段后处理」：若不确定要保留本地录像，先移除默认 `rm`，或配置为安全保留策略。

### 步骤 5：执行一次短任务并验收

开播（或用短视频 / 测试素材）触发一次「录制 → 上传 → 投稿」。验收标准：

- **首次录制**：录像文件出现，后处理结束后文件仍保留（除非你明确配置了删除），直播历史状态正常。
- **首次录制并投稿**：任务管理显示投稿完成，且 B站创作中心能看到稿件。

> 建议首次验证使用**专用、低权限的测试账号**与合法测试内容，不要用生产主账号。
