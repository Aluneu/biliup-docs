# 录制分段、画面遮挡与本地合并

本页讲三件容易混在一起的事：**怎么分段**、**怎么给录像打码**、**怎么把本地多个分段拼成一个文件**。

::: tip 一句话结论
分段时长 / 遮挡 / AAC 时间戳检查都是自动的；**把多个本地分段拼成单文件默认要手动做**（biliup 没有「下播后自动合并」开关），多分 P 投稿与「直播历史」里的场次合并也**不会**拼接文件。
:::

---

## 一、分段时长（segment_time）

### 在哪里设置

| 位置 | 作用范围 |
|---|---|
| 空间配置 → 全局设置 → 视频分段时长 | 全局默认 |
| 直播管理 → 房间 → 配置覆写 → 下载设置 | 只对这个主播生效 |

房间级有三种状态：

- **跟随全局**（默认）；
- **不按时长分段**——仍会按大小（`file_size`）与断流切段；
- **预设或自定义**。

### 写法

`00:07:30`、`7:30`、`450` 三种写法等价，支持小数秒。实际切段位置落在**关键帧边界**上，所以每段会比设定值略长。

### 碎片过滤（filtering_threshold）

低于阈值（默认 20 MB）的短段不进入投稿与后处理。**启用遮挡时，遮挡先执行、再按原始大小过滤**——想保留短素材，把 `filtering_threshold` 设为 `0`。

## 二、画面遮挡

### 入口

- 直播管理 → **画面遮挡**；
- 或 房间 → 配置覆写 → **画面遮挡（实验性）**。

### 操作步骤

1. 打开编辑器，先取得**真实直播截帧**（房间未开播时无法新增区域）；
2. 勾选「启用画面遮挡功能」；
3. 在画面上拖拽圈选区域，选择效果：
   - **马赛克**：块大小 `4`–`64`；
   - **模糊**：强度 `1`–`100`；
   - **纯色**：`#RRGGBB`。
4. 保存。区域按**百分比**保存，最小 1%，最多 **32 个**；
5. 「刷新画面」会重抓一帧并**保留已画区域**。

> 编辑器**不预览** FFmpeg 的实际处理效果；马赛克 / 模糊不保证内容不可辨认，敏感内容请自行确认强度。

### 行为与限制

- 分段关闭后自动处理，**处理后的分段才会进入投稿与切片导出**；上传器是 `Noop` 也会执行遮挡。
- 切片工作台的「快速剪 / 精确剪」**不会**在导出时再加遮罩或弹幕——它们只切已经落盘的（已遮挡）文件；需要额外加遮挡 / 图片 / 弹幕，请用「合成导出选段」，见[录后合成](/guide/tutorials/post-recording-render.html)。
- **不兼容 `sync-downloader`**（边录边传）。
- 预览、DVR 回放、`.part` 临时文件与失败的原片**仍含原画面**；处理失败会保留原始文件（以及 `.unmasked` 隔离文件）——它们都是原片，不要当成安全输出。
- 需要一份**含 `libx264` 与滤镜**的 FFmpeg；视频会重编码为 H.264。遮挡只增加 CPU 占用，不需要 GPU。

## 三、FLV 音频时间戳自动修复

已关闭的落盘 FLV 分段会自动检查 AAC 音频包时间戳（**没开遮挡也会查**）：

- 只有出现**重复或回退**时才修正：音频重编码为 192 kbps AAC、视频直接复制；
- 输出要通过严格递增校验才会替换原文件，失败则保留原片且不进入投稿 / 后处理；
- **不追溯**已有录像，也不处理边录边传。

---

## 四、未完成的录像

断流、出错、暂停、删房间、退出程序，biliup 都**保留已写下的内容**：

- FLV / TS 照常成为一个分段并进入上传；
- HLS fMP4 只保留收满的整片分片；
- ffmpeg 录 MP4 中止时不进上传，但留下 `.mp4.part`。

详见[全局设置 · 未完成的录像](/guide/getting-started/配置/global-config.html)。

## 五、把本地分段合并成一个文件

### 1. 先确认各段参数一致

```bash
ffprobe -v error -show_entries stream=codec_name,width,height,r_frame_rate,sample_rate,channels,time_base <分段文件>
```

编码、分辨率、帧率、采样率、声道、`time_base` 必须一致，否则不能 `-c copy`。

### 2. 写 `list.txt`

```
ffconcat version 1.0
file '第一段.flv'
file '第二段.flv'
```

### 3. 合并

```bash
ffmpeg -hide_banner -n -f concat -safe 0 -i list.txt \
  -map 0:v:0 -map '0:a?' -c copy -movflags +faststart "合并录像.mp4"
```

注意事项：

- 排除 `.part`、`.unmasked`、`.biliup-*` 临时文件、弹幕 XML 与已合并的文件；
- 参数不一致时不能 `-c copy`，必须重编码；
- 目标容器不适配 MP4 时，可改用 `.mkv` 并去掉 `+faststart`；
- 合并**不会修复**坏段与花屏。

### 4. 想自动化

在「编辑主播 → 后处理」加一个 `run` 步骤：文件路径经标准输入按换行传入。注意默认的 `rm` 步骤会先删文件，合并脚本要排在它前面或移除 `rm`。
