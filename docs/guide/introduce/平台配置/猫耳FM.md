::: info
* 直播间链接格式：`https://fm.missevan.com/live/123456`（123456 为房间号）。
* 猫耳 FM 为**纯音频流**，录制结果为音频文件，不含视频画面。
:::


::: tip
* 如遇无法录制，可尝试将下载器切换为 `streamlink` 或 `ffmpeg`，详见[下载器的选择](../配置/GlobalConfig.html#下载插件-downloader)。
:::
