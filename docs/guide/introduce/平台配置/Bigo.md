> [!IMPORTANT]
> * 直播间链接格式：`https://www.bigo.tv/123456`（123456 为频道号）。
> * Bigo **无需特殊配置**，默认使用 `stream-gears` 下载器即可录制。

> * 如遇无法录制，可尝试将下载器切换为 `streamlink` 或 `ffmpeg`，详见[下载器的选择](../配置/GlobalConfig.html#下载插件-downloader)。
