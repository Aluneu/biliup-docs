::: info
* 直播间链接格式：`https://www.huya.com/123456`（123456 为房间号）。
* 默认使用 `stream-gears` 下载器即可录制，无需额外安装。
* 虎牙支持弹幕录制，开启后弹幕以 B站兼容 XML 格式保存。
* 虎牙提供 CDN 线路优选，画质不稳定时可尝试切换线路。
:::


::: tip
* 如遇无法录制或花屏，可尝试将下载器切换为 `streamlink` 或 `ffmpeg`，详见[下载器的选择](../配置/GlobalConfig.html#下载插件-downloader)。
:::

## 弹幕录制（huya_danmaku）

* 虎牙弹幕通过 WebSocket（TARS 协议）获取，开启「弹幕录制」后即可录制对应直播间的弹幕。
* 弹幕输出为 B站兼容的 XML 格式，可配合 [DanmakuFactory](https://github.com/hihkm/DanmakuFactory) 进行弹幕压制。

----

## 画质与编码

### 码率上限（huya_max_ratio）

* 限制录制码率上限，避免过高码率导致文件过大或写入失败。

### 协议选择（huya_protocol）

* 选择直播流协议（如 FLV / HLS），默认即可。

### 编码选择（huya_codec）

* 选择视频编码：`264` / `265`，默认即可。

### 二次编码（huya_imgplus）

* 开启后对画面进行二次编码处理。默认关闭。

----

## CDN 线路

### CDN 回退（huya_cdn_fallback）

* 主线路不可用时自动回退到其他 CDN 节点。建议开启以提高稳定性。

### 移动端 API（huya_mobile_api）

* 使用移动端 API 获取直播流，部分房间可能更稳定。默认关闭。

### WUP 协议（huya_use_wup）

* 使用 WUP 协议获取直播流。默认关闭。
