> [!IMPORTANT]
> * 直播间链接格式：`https://live.douyin.com/123456`（123456 为房间号）。
> * 抖音**风控严格**，部分直播（尤其是直播首页 `douyin.com` 非 `live.douyin.com` 域名）**需要 Cookie 才能录制**。
> * 抖音支持弹幕录制，开启后弹幕以 B站兼容 XML 格式保存。

> [!WARNING]
> * 抖音直播首页（非 `live.douyin.com` 域名）必须提供 Cookie 才能录制，否则会直接失败。

> [!TIP]
> * Cookie 配置见下方「抖音 Cookie」，或在[登录方式详解](../introduce/login.html)中了解网页 Cookie 文件登录。

----

## 画质（douyin_quality）

* 选择录制画质：`origin`(原画) / `uhd` / `hd` / `sd` / `ld` / `md`。默认原画。

## 直播流协议（douyin_protocol）

* 选择直播流协议：`flv` / `hls`。默认 `flv`。

## 弹幕录制（douyin_danmaku）

* 开启后录制抖音弹幕，弹幕输出为 B站兼容的 XML 格式，可配合 [DanmakuFactory](https://github.com/hihkm/DanmakuFactory) 进行弹幕压制。默认关闭。

## 双屏直播录制（douyin_double_screen）

* 开启后录制双屏直播内容。默认关闭。

## 真原画（douyin_true_origin）

* 开启后尝试录制抖音真原画（HEVC 编码）。默认关闭。

----

## 抖音 Cookie（user.douyin_cookie）

* 填写抖音 Cookie（避免风控、解锁首页直播录制）。
* 可通过[网页 Cookie 文件登录](../introduce/login.html#方式五网页-cookie-文件登录)加载，或手动填入 Cookie 文本。

> [!IMPORTANT]
> * 当 Cookie 文本与 Cookie 文件同时存在，将优先加载文件。
