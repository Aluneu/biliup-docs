> [!IMPORTANT]
> * 直播间链接格式：`https://live.kuaishou.com/u/用户名`（用户名为主播 ID）。
> * **需中国大陆 IPv4 家宽 IP** 才能稳定录制，海外 / 机房 IP 极易触发风控导致录制失败。
> * 快手风控严格，建议不要在短时间内频繁操作账号。

> [!WARNING]
> * 如使用代理或数据中心 IP 录制快手，很可能直接失败或账号异常，请优先使用本地家宽网络。

> [!TIP]
> * 如遇无法录制，可尝试将下载器切换为 `streamlink` 或 `ffmpeg`，详见[下载器的选择](../Config/GlobalConfig.html#下载插件-downloader)。
