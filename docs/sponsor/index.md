# 🍵 赞助

如果你正在使用 biliup，或觉得它对你的直播录制 / 上传有帮助，欢迎通过赞助支持项目的持续开发。

你的赞助将用于：

- 维持项目所需的服务器与带宽成本（如 WebUI 演示站、更新分发）
- 激励核心开发者持续修复 Bug、跟进 B 站接口变化
- 支持新平台接入与功能迭代

## 如何赞助

biliup 通过 **GitHub Sponsors** 接收赞助：

- 👉 [GitHub Sponsors · biliup](https://github.com/sponsors/biliup)

在 GitHub Sponsors 页面你可以选择按月或一次性赞助，并查看所有赞助者名单。

## 其他支持方式

如果不方便赞助，也欢迎通过这些方式支持项目：

- 在 GitHub 上为项目 [Star](https://github.com/biliup/biliup) ⭐
- 参与讨论、提交 Issue 与 Pull Request
- 向身边的朋友推荐 biliup

感谢每一位支持者，让 biliup 能一直免费、开源地服务大家 💙
